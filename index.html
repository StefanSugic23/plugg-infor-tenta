DOM

Vad är DOM? DOM står för Document Object Model. Det är ett sätt för JavaScript att läsa och ändra HTML-element på en webbsida. Tänk så här: - HTML skapar innehållet. - CSS bestämmer hur innehållet ser ut. - DOM med JavaScript gör att du kan ändra innehållet och reagera på användarens handlingar.
